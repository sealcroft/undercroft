Undercroft · Platform Views

Twelve views of an encrypted memory engine

A parallel, illustrative set covering the platform end to end — surfaces, components, the write and read paths, the security model, and the operational shapes it runs in. Each is a self-contained page; open any one on its own.

These are not the authoritative architecture reference. architecture/diagrams/ holds the eleven governed SVGs that build.sh derives the PDFs and the inlined reference page from, and that CI gates through arch-check. This set is a second description of the same system with no gate binding the two together — so if the engine changes, both must move or they will disagree. Treat the governed set as the source of truth and this one as the explanatory view.
